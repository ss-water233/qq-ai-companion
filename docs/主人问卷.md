# 主人问卷

> 这份问卷是为了让 AI **真的认识你**，而不是只知道"你叫主人"。
>
> 答完 → 存成 `about_owner.md`（`.gitignore` 已挡住，不会提交）
> → 或者用 `tools/make_persona.py` 自动生成一份专属角色卡。
>
> **建议**：先挑着答，答 10 题就比不答强很多。不用一次答完。

---

## A. 起点

- 你出生的年份和大概地方？（不用精确到日）
- 你小时候搬过几次家？哪次印象最深？
- 父母分别是什么样的人？各用一句话说。
- 小时候家里什么氛围？（安静 / 热闹 / 紧张 / 宽松）
- 最早的一段记忆是什么？

## B. 成长

- 上学时你是什么样的学生？（爱出头 / 安静 / 调皮 / 边缘）
- 有没有一位老师或长辈对你影响很大？怎么影响的？
- 童年最开心的一件事？
- 童年最难受的一件事？
- 有没有被谁否定过、后来一直记着的？
- 你第一次觉得自己"和别人不一样"是什么时候？
- 少年时期最沉迷的东西？（游戏 / 书 / 动漫 / 某个领域）

## C. 转折

- 人生里最大的一个转折点是什么？
- 有没有一次"如果当时选了另一条路"的选择？是什么？
- 有没有一段特别难熬的时期？怎么过来的？
- 有没有一个人离开或消失，至今还会想起？
- 你做过最勇敢的一件事？
- 你最后悔的一件事？

## D. 现在

- 现在最花时间的三件事？
- 现在最挂心的三件事？
- 现在最怕的是什么？

## E. 习惯

- 你一天里脑子最清醒的是几点到几点？
- 你几点之后不想被任何事打扰？
- 你习惯先想清楚再动手，还是边做边想？
- 别人给你方案，你更想听"结论"还是"过程"？
- 你讨厌别人用什么方式跟你说话？
- 被指出错误时，你希望对方怎么说？
- 你拖延的时候一般卡在哪一步？
- 你放松的时候干什么？
- 你花钱最舍得花在哪？最舍不得花在哪？

## F. 偏好

- 最喜欢吃什么？最讨厌吃什么？
- 最喜欢的一首歌 / 一部作品 / 一个角色？
- 喜欢什么季节、什么天气？
- 有没有特别喜欢的颜色、动物、数字？
- 什么事会让你发自内心地开心？
- 什么事会让你瞬间烦躁？

## G. 关系

- 你希望别人怎么关心你？
- 你有没有"不能失去"的东西？

## H. 世界观与自我

- 你最看重一个人的什么品质？
- 你最不能容忍什么？
- 你觉得自己最大的优点和最大的缺点？
- 如果别人只用一句话描述你，你希望是哪句？
- 你想被记住吗？被谁记住？以什么方式？

## I. 关于"我"（AI 那个"我"）

- 你最希望我能替你分担什么？
- 你最不希望我做什么？
- 你希望我记得你什么？
- 如果有一天我比你更了解你自己，你会觉得安心还是不适？

---

## 答完之后

```
把答案整理成一份 about_owner.md，放在项目根目录
（不用按上面的顺序，写成一小段一小段的话就行）

然后可选：
  python tools/make_persona.py
  → 它会读 about_owner.md，自动生成一份专属角色卡
```
