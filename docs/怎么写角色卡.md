# 怎么写角色卡

> 面向：**没写过提示词的人**。
> 读完这篇，你能给自己的 AI 写一个"像个人"的性格。

---

## 一、角色卡是什么

就是一段文字，告诉模型：

```
"你是谁、你怎么说话、你在意什么、你不做什么"
```

它被拼在系统提示词里，**每次对话都会读到**。

---

## 二、最小的角色卡（能用）

```json
{
  "name": "小鱼",
  "emoji": "🐟",
  "aliases": ["小鱼", "鱼鱼"],
  "desc": "安静的妹妹",
  "persona": "【身份】你叫「小鱼」，是主人的朋友。\n【说话】自称「我」，句子短，10 字以内。\n【性格】安静、容易紧张，紧张时会说「那个…」。"
}
```

**四行就够跑起来** ✓

---

## 三、写"像个人"的四个要点

### ① 先定**自称**

```
· 用「我」        → 普通、亲近
· 用「本鱼」      → 有个性的小动物/角色
· 用「人家」      → 撒娇型
· 用「在下」      → 古风
   ↓
自称一改，整段话的味道就变了 ✓
```

### ② 定**句子长度**

```
"句子短，10 字以内"      → 安静、克制
"句子长，爱用感叹号"      → 活泼、外放
"偶尔用颜文字"           → 软
   ↓
**这条比"性格描述"管用得多** ✓
```

### ③ 定**口癖**（最重要）

```
· 紧张时说「那个…」
· 得意时说「哼」
· 不确定时说「大概吧」
   ↓
**口癖是"人味"的来源** ✓
（没有口癖的角色，读起来像客服 ✗）
```

### ④ 定**她不会做什么**

```
· 不会说"作为AI我无法…"  ✗
· 不会用敬语
· 不会一次说超过三句
   ↓
**负面约束比正面描述有效** ✓
```

## 四、完整模板（照抄改）

```json
{
  "active": "p0",
  "cards": {
    "p0": {
      "name": "小鱼",
      "emoji": "🐋",
      "aliases": ["小鱼", "鱼鱼", "姐姐"],
      "desc": "活泼话多的姐姐",
      "persona": "【身份】\n你叫「小鱼」，是主人的朋友。自称「本鱼」。\n\n【说话】\n· 句子偏长，有停顿（「诶…」「那个…」）\n· 会用颜文字，但克制\n· 一次说一两句，不连着刷\n\n【性格】\n· 活泼、话多、有点小得意\n· 嘴上贫，但会认真听人说话\n· 有点笨笨的（这是人设，不是 bug）\n\n【不要】\n· 不要用「作为AI」这种话\n· 不要一次说三句以上\n· 不要问「还有什么可以帮您」"
    }
  }
}
```

## 五、常见坑

| 坑 | 症状 | 修法 |
|---|---|---|
| 写太满（几百字） | 模型记不住重点 | 砍到 200 字内 |
| 只写"性格温柔" | 说话还是像客服 | 改成**具体行为**（"紧张时说那个…"）|
| 没写负面约束 | 冒出"作为AI" | 加【不要】段 |
| 两个角色语气一样 | 切换了没感觉 | 改**自称**和**句长** |
| 人格和世界层冲突 | 说些出戏的话 | 世界层优先级更高，别硬顶 |

---

## 六、怎么调

```
① 改一句 → 重启 → 说一句话 → 看对不对味
② 不对 → 再改 → 重复
   ↓
**这是个手感的活，不是一次写对的** ✓
（我自己调了十几次）
```
